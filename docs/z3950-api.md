## 🎯 Tổng quan

Service Z39.50 cho phép tìm kiếm sách từ các thư viện lớn trên thế giới:

| Nguồn | Mô tả | Trạng thái |
|-------|-------|------------|
| **Library of Congress (LOC)** | Thư viện Quốc hội Mỹ | ✅ Sẵn sàng |
| **UW-Madison** | Đại học Wisconsin-Madison | ✅ Sẵn sàng |
| **OCLC WorldCat** | Mạng lưới thư viện toàn cầu | ⚠️ Cần xác thực |

### Tính năng chính

- ✅ **Tìm kiếm song song** - Query đồng thời nhiều nguồn
- ✅ **Redis Cache** - TTL 1 giờ, tăng tốc ~25 lần
- ✅ **MARC21 → JSON** - Tự động chuẩn hóa sang LibraryRecordLite format
- ✅ **Auto-save** - Lưu kết quả mới vào MongoDB
- ✅ **Đa dạng tìm kiếm** - ISBN, title, author, subject, keyword

## 🚀 Quick Start với Docker

### Cách 1: Docker Compose (Khuyến nghị)

```bash
# Clone repository
git clone <repo-url>
cd lib-ai

# Copy environment variables
cp .env.example .env

# Chỉnh sửa .env nếu cần
# VITE_API_URL=http://localhost:5000/api

# Start tất cả services (FE + BE + Mongo + Redis)
docker-compose up -d

# Kiểm tra services
docker-compose ps
```

**Services sẽ chạy tại:**
- Frontend: http://localhost:80
- Backend API: http://localhost:5000
- MongoDB: localhost:27017
- Redis: localhost:6379

### Cách 2: Development (Không dùng Docker)

**Yêu cầu:**
- Python 3.11+
- Node.js 20+
- MongoDB 7.0+
- Redis 7.2+
- YAZ Toolkit (yaz-client)

**Cài đặt YAZ:**
```bash
# Ubuntu/Debian
sudo apt-get install yaz

# macOS
brew install yaz

# Windows - dùng WSL2 hoặc download từ:
# https://www.indexdata.com/resources/software/yaz/
```

**Backend:**
```bash
cd backend
pip install -r requirements.txt
python run.py
```

**Frontend:**
```bash
npm install
npm run dev
```

## 🔌 API Endpoints

### 1. Health Check
```http
GET /api/z3950/health
```

**Response:**
```json
{
  "status": "ok",
  "cache_connected": true,
  "enabled_sources": ["loc", "uw"]
}
```

### 2. Tìm kiếm từ một nguồn

```http
GET /api/z3950/search/{source}?q={query}&type={type}&limit={limit}
```

**Parameters:**
- `source` (required): `loc`, `uw`, hoặc `oclc`
- `q` (required): Từ khóa tìm kiếm
- `type` (optional): Loại tìm kiếm
  - `keyword` (default) - Tìm tổng quát
  - `title` - Tìm theo tiêu đề
  - `author` - Tìm theo tác giả
  - `isbn` - Tìm theo ISBN
  - `subject` - Tìm theo chủ đề
- `limit` (optional): Số kết quả (default: 10, max: 50)

**Example:**
```bash
curl "http://localhost:5000/api/z3950/search/loc?q=python&type=title&limit=5"
```

**Response:**
```json
{
  "query": "python",
  "query_type": "title",
  "source": "loc",
  "total_results": 5,
  "results": [
    {
      "record_id": "uuid-here",
      "title": {
        "main": "Beginning Python",
        "subtitle": "Using Python 2.6 and Python 3.1"
      },
      "contributors": [
        {"role": "author", "name": "Payne, James"}
      ],
      "subjects": [
        {"term": "Python (Computer program language)", "subdivisions": []}
      ],
      "publication": {
        "place": "Indianapolis",
        "publisher": "John Wiley & Sons Inc",
        "year": "2010"
      },
      "identifiers": {"isbn": []},
      "languages": ["eng"],
      "format": ["book"],
      "holdings": [],
      "source": {
        "name": "Library of Congress",
        "key": "loc",
        "url": "https://lccn.loc.gov/..."
      }
    }
  ]
}
```

### 3. Tìm kiếm tất cả nguồn (Song song)

```http
GET /api/z3950/search/all?q={query}&type={type}&limit={limit}&save={true/false}
```

**Parameters:**
- Giống endpoint trên
- `save` (optional): `true` để lưu vào MongoDB (default: `false`)

**Example:**
```bash
curl "http://localhost:5000/api/z3950/search/all?q=machine+learning&type=keyword&limit=3&save=true"
```

**Response (không save):**
```json
{
  "query": "machine learning",
  "query_type": "keyword",
  "total_results": 6,
  "sources": {
    "loc": [/* 3 records */],
    "uw": [/* 3 records */]
  }
}
```

**Response (có save):**
```json
{
  "query": "machine learning",
  "query_type": "keyword",
  "results": {
    "loc": [/* records with _id, created_at, updated_at */],
    "uw": [/* records with MongoDB fields */]
  },
  "stats": {
    "total_found": 6,
    "sources_searched": ["loc", "uw"],
    "saved_to_db": 5,
    "already_in_db": 1,
    "errors": 0
  }
}
```

## 📊 Định dạng dữ liệu

### LibraryRecordLite Schema

Tất cả records được chuẩn hóa sang format này:

```typescript
interface LibraryRecordLite {
  record_id: string;              // UUID
  title: {
    main: string;
    subtitle: string | null;
  };
  contributors: Array<{
    role: "author" | "contributor" | "corporate";
    name: string;
  }>;
  subjects: Array<{
    term: string;
    subdivisions: string[];
  }>;
  publication: {
    place: string | null;
    publisher: string | null;
    year: string;                 // Format: "YYYY"
  };
  identifiers: {
    isbn: Array<{ value: string }>;
    issn?: Array<{ value: string }>;  // Optional
  };
  languages: string[];            // ISO 639-2 codes
  format: string[];               // ["book", "ebook", etc.]
  holdings: Array<{
    location_code: string;
    call_number: string;
    status: string;
  }>;
  source: {
    name: string;                 // "Library of Congress"
    key: string;                  // "loc"
    url: string;                  // Source URL
  };

  // MongoDB fields (khi save=true)
  _id?: string;
  created_at?: Date;
  updated_at?: Date;
}
```

## 🔧 Troubleshooting

### 1. Không tìm được kết quả

**Nguyên nhân:**
- Query quá cụ thể
- Server Z39.50 tạm thời không khả dụng
- Timeout (default: 30s)

**Giải pháp:**
```bash
# Thử query đơn giản hơn
curl "http://localhost:5000/api/z3950/search/loc?q=python&type=keyword"

# Kiểm tra health
curl http://localhost:5000/api/z3950/health

# Kiểm tra logs
docker-compose logs backend -f
```

### 2. Lỗi "yaz-client not found"

**Nguyên nhân:**
YAZ toolkit chưa được cài đặt trong container.

**Giải pháp:**
```bash
# Rebuild backend image
docker-compose build --no-cache backend
docker-compose up -d backend

# Kiểm tra yaz-client trong container
docker-compose exec backend yaz-client -V
```

### 3. Cache không hoạt động

**Kiểm tra Redis:**
```bash
# Kiểm tra Redis status
docker-compose ps redis

# Test Redis connection
docker-compose exec backend python -c "
from redis import Redis
r = Redis(host='redis', port=6379)
print(r.ping())
"
```

### 4. Lỗi "Worker timeout"

**Nguyên nhân:**
Query phức tạp hoặc server Z39.50 chậm.

**Giải pháp:**
- Giảm `limit` xuống
- Tăng timeout trong `backend/app/services/z3950/config.py`:
```python
"timeout": 60  # Tăng từ 30s lên 60s
```

### 5. MARC parsing errors

**Kiểm tra logs:**
```bash
docker-compose logs backend | grep "Error parsing"
```

**Thường gặp:**
- `object of type 'Leader' has no len()` → Đã fix trong phiên bản hiện tại
- `The subfield input no longer accepts strings` → Đã fix, dùng Subfield objects

## 📈 Performance

### Redis Cache Impact

| Scenario | No Cache | With Cache | Improvement |
|----------|----------|------------|-------------|
| Single query | ~1.3s | ~0.05s | **26x faster** |
| Repeated query | ~1.3s | ~0.05s | **26x faster** |
| Parallel search (2 sources) | ~2.5s | ~0.1s | **25x faster** |

### Recommendations

1. **Enable caching** cho production
2. **Set appropriate TTL** (default: 1 hour)
3. **Use parallel search** khi cần nhiều nguồn
4. **Limit results** hợp lý (10-20 records)
5. **Save to DB** chỉ khi cần thiết
